# 技术分享、沟通与提问参考资料 (References)

## 1. 酷壳 (CoolShell - 陈皓 / 左耳朵耗子)
* **如何做一个有质量的技术分享**：
  * 链接：https://coolshell.org/articles/21589.html
  * 核心心法：Why 比 What 重要，How 比 What 深入；问题模型 $\to$ 方案对比 $\to$ 底层机制 $\to$ 最佳实践；Less is More。

## 2. Stack Overflow 官方指南
* **How do I ask a good question? (如何提出一个好问题)**：
  * 链接：https://stackoverflow.com/help/how-to-ask
  * 核心心法：MRE 原则（Minimal, Reproducible Example 最小可复现示例）；自解释标题；背景先于代码；预期 vs 实际现象；杜绝代码与日志截图。
